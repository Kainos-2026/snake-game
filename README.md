# 🐍 Classic Snake Game

A clean, responsive, and lightweight implementation of the classic Snake arcade game built with **Vanilla JavaScript** and **HTML5 Canvas**.

---

## 🎮 How to Play
1. **Start**: Click the "Start Game" button to begin.
2. **Control**: Use your **Arrow Keys** (Up, Down, Left, Right) to navigate the snake.
3. **Objective**: Eat the food to grow your length and increase your score.
4. **Game Over**: The game ends if you hit the walls or collide with your own tail.

## ✨ Features
- **Canvas Rendering**: High-performance rendering using the HTML5 Canvas API.
- **Real-time Scoring**: Track your progress as you play.
- **Responsive Logic**: Smooth grid-based movement and collision detection.
- **Zero Dependencies**: Pure HTML, CSS, and JS—no frameworks required.

## 🛠️ Tech Stack
- **HTML5**: Structured with semantic tags and a `<canvas>` element.
- **CSS3**: Styled for a modern, centered game container.
- **JavaScript (ES6)**: Game loop, collision logic, and state management.
